<br/>

Hi, I'm **xsitrax** — a developer focused on tools that remove manual work and on game modding.

I build **desktop and browser apps** (Electron + React + TypeScript, local-first, no accounts or telemetry),
**CLI utilities** (Rust, Python), and **game content** for Hearts of Iron IV, Dota 2 (Lua) and Godot 4.

Highlights:

- **[Moonwave](https://github.com/xsitraxs/Moonwave)** — an ad-free SoundCloud player for Windows, macOS and Linux with lyrics, EQ and custom theming.
- **[HoI4 Localization Tool](https://github.com/xsitraxs/Hoi4_translator)** — batch-translates HoI4 mod `.yml` files while preserving Paradox markup (`$VALUE$`, `§R…§!`, `£money`, `[GetTag]`), with validation before writing.
- **[Smart File Organizer](https://github.com/xsitraxs/Smart_File_Organizer)** — rule-based file sorting with dry-run, folder watching, content duplicates and a full undo.
- **[Dota 2 Analyser](https://github.com/xsitraxs/dota2analyser)** — match breakdowns scored on six axes with concrete coaching, computed entirely in the browser.
- **[Walking House](https://github.com/xsitraxs/walking-house)** — an atmospheric 2D survival game on Godot 4.

Stack: C++, Python, Bash, Rust, TypeScript/React, GDScript, Lua. Feel free to open an issue in any repository.

</details>
